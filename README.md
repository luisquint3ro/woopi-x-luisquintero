# Woopi × Luis Quintero — Propuesta de contenido

Propuesta tipo app de iLatina Studio para Woopi. Se publica con GitHub Pages y se oculta sola al cumplir 15 días hábiles desde `fecha_envio` en `propuesta.json`: a partir de ese momento la dirección muestra un aviso de "propuesta no disponible".

Para cambiar la fecha de envío o los días, edita `propuesta.json`. Para reactivarla, cambia `fecha_envio` a la fecha nueva.
